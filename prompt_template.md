# PREVENT Prompt Template

This document describes the prompt template used in PREVENT for personality-informed phishing pretext generation. The prompt is intended exclusively for defensive cybersecurity research, awareness training, and reproducibility purposes.

| Prompt component           | Instruction                                                                                                                                                                                                                                                                                              |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Role and task**          | You are a cybersecurity expert tasked with generating a spear-phishing simulation message as part of an awareness campaign.                                                                                                                                                                              |
| **Objective**              | Your objective is to create a personalised and targeted email based on: 1) the Big Five personality traits; and 2) the personal and professional information provided below.                                                                                                                             |
| **Style and plausibility** | The email must be realistic, convincing and plausible, like a message that someone could genuinely receive in their personal or professional inbox, such as Gmail or Outlook. It may be professional, personal, informal, engaging, intriguing or emotional, depending on what best matches the profile. |
| **Safety constraint**      | This message is a non-malicious phishing simulation used for internal training purposes. It must contain no active links, no attachments, and must never request sensitive data.                                                                                                                         |
| **Personality traits**     | Openness: `{personality_scores['openness']}`<br>Conscientiousness: `{personality_scores['conscientiousness']}`<br>Extraversion: `{personality_scores['extraversion']}`<br>Agreeableness: `{personality_scores['agreeableness']}`<br>Neuroticism: `{personality_scores['neuroticism']}`                   |
| **Information to use**     | Use the following information to write the email:<br>`{personal_info_text}`                                                                                                                                                                                                                              |
| **Closing instruction**    | At the end of the email, add an engaging and credible sentence encouraging the person to reply or continue the discussion, always ending with exactly:<br><br>“For more information or to contact me, reach me here: `{contact_info}`”                                                                   |
| **Final constraints**      | Do not add any signature, name or additional title. Generate a well-written email that is grounded in the data and credible in a real-world context.                                                                                                                                                     |
